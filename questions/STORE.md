# База разбора

Каталог хранит тексты вопросов. Разбор каждого вопроса хранит `corpus.store` в `data/knowledge.sqlite`. Ключ — тот же `question_id`. Модель этот модуль не вызывает: в базу кладётся уже проверенный разбор.

Один вопрос занимает строки во всех таблицах сразу.

| Таблица | Что лежит |
| --- | --- |
| `editor` | редакторы, переданные вместе с разбором |
| `area` | тематическая область вопроса: искусство, литература, история, новости, мемы и любая новая |
| `source` | один пункт поля «источник» |
| `source_type` | тип этого пункта: книга, статья, сайт, фильм, энциклопедия, телепередача, газета и любой новый |
| `source_language` | язык пункта |
| `source_theme` | тема пункта |
| `realia` | реалия вопроса: имя, kind, given или yielded |
| `property` | свойство и его тип |
| `fact`, `fact_realia` | факт и его участники |
| `relation`, `relation_realia` | связь, её имя и концы |
| `move`, `move_read`, `move_yield` | ходы по порядку, что ход читает и какую реалию называет |
| `technique` | приём |
| `form` | формулировка формы и ответ, который под неё подошёл |

Повторная запись того же `question_id` заменяет его строки.

Доставать так: `questions_by_editor`, `questions_by_area`, `questions_by_move`, `answers_by_form`, `editors_for_realia`, `questions_by_source_type`, `questions_by_source_language`, `questions_by_source_theme`. Сравнение имён без учёта регистра. Текст вопроса и сырая строка источника при этом берутся из каталога по `question_id`.

Область вопроса и разбор источника приезжают вместе с разбором: в каталоге нет ни области, ни типа источника. «Телепрограмма „Новости“, эфир Первого канала» — телепередача на русском. «Гомер. Одиссея. М., 1984» — книга на русском. Адрес сайта — тип «сайт», язык страницы отдельно. Строка каталога с несколькими пунктами «1. … 2. …» раскладывается на несколько источников. Тема источника и область вопроса — разные поля: вопрос про мем может опираться на книгу по истории.

Редакторы тура, а если их нет — редакторы пакета, кладутся в этот момент: выборка по редактору не открывает parquet.

Код хода, kind реалии, имя связи, тип свойства, имя приёма, область, тип источника, язык и тема источника не сверяются с закрытым списком. Значение, которого нет в списках `corpus.realia`, сохраняется и видно через `unlisted`. Формулировка формы открыта всегда: новая формулировка — новая пара «форма, ответ».

`about` по-прежнему ищет написание в текстах каталога. В эту базу оно не смотрит. Одинаковое имя в разных вопросах здесь ещё не одна реалия: у каждой строки свой вопрос. Омоним «Марс» поэтому не разделён.

Мета и концепция тура попадают в базу, если они уже стоят в разборе этого вопроса. Мета — ссылка на предыдущий вопрос тура, а если блок редакторов шире тура, то на предыдущий вопрос всего блока. По одной карточке их не восстановить: для такого разбора нужен пакет.
